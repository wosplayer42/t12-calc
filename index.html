How to use this calculator

Plan T12 / Exalted research costs by setting current and target levels for each node. Totals update live in the Summary panel.

  1. Set research speed (and optional inventory) in the left sidebar so time and “still needed” are accurate.
  2. Enter current levels for nodes you already researched. Leave targets empty until you plan the next steps.
  3. Use Quick targets for common plans (Troop Skill, Ideal Joiner, max Molten tiers), or pick levels node-by-node. Partial applies to one camp; All applies to every camp. Tap a camp header to focus Partial selection.
  4. Keep Auto-raise in-tree prerequisites on so gear / Molten floors rise with your targets. A toast appears when targets are adjusted.
  5. Open the Milestone cost tables for from-zero totals (Troop Skill, Ideal Joiner, support). Tree badges show State 1721 priority (Go to lvl 20 1st / 2nd / 3rd). Game unlock chains outside the tree: wiki research page.

T12 / Exalted only — no T11 Helios. Meat/Wood costs count as both resources. Progress saves in this browser.
